# 长尾「工具 + SEO」页面规划（2026-09-12）

目标：新增一批和 `/audio-to-text` 同类型的页面（页面内嵌转录工具 + 该场景专属的说明内容），既做长尾 SEO，也补上站点页数太少的问题（AdSense 拒审原因之一）。

## 数据来源

- **竞品 sitemap**：抓取 24 个竞品，把转录相关的着陆页 URL 归并成搜索意图，统计每个意图有几家在做。几家同时在做，说明需求得到了验证。
  - 竞品名单：TurboScribe、Notta、VEED、HappyScribe、Sonix、Maestra、Transkriptor、Descript、Kapwing、Flixier、Riverside、Otter、Podcastle/Async、Restream、NoteGPT、VOMO、GoodTape、Cockatoo、subtitles.app（freesubtitles.ai）、WhisperWeb.dev / .app / .net、usewhispy、speechnotes。
  - 最接近的同类是 **WhisperWeb.dev**：同样在浏览器里跑 Whisper，已经做了格式页、字幕转换器、视频转文字、音频格式转换这几类页面。
- **Google 联想词**：英文、简体中文、日文各查了一批，只能说明大家怎么搜，不代表搜索量。
- **可行性**：按 EarScribe 现有能力判断。支持的输入是浏览器能解码的音频：MP3 / WAV / M4A / OGG / Opus / FLAC / AAC / WebM。以下功能都没有：导入链接、区分说话人、翻译、实时转写、视频输入。

## 每个新页面都要守的规则（避免被 AdSense 当成「门页 / 批量内容」）

1. 页面必须嵌入可用的工具，不能只放一个跳到首页的按钮。
2. 至少放一样**只属于这个页面**的东西：一个真实样例（这个场景的录音加上它的转录结果），或者这个格式、这个平台特有的事实（文件在哪、叫什么、怎么导出、有哪些坑）。
3. 标题和正文用自然语言写，不要把 free / unlimited / no sign-up 塞进每个小标题。
4. 先出英文。只有联想词证明中文、日文也有人这么搜，才出 zh-CN / ja 版本。不要铺到 27 个语种。
5. 和现有 5 个页面意图重合的，并进现有页面，不单独开页。

## 不建议做

| 意图 | 原因 |
|---|---|
| YouTube / TikTok 链接转文字（17 家在做） | 需要服务端下载，涉及平台条款，和"不上传"的定位冲突 |
| 法律 / 医疗转录（8–9 家） | 高风险领域，准确性承诺做不到，对 AdSense 也敏感 |
| 逐字稿（verbatim） | Whisper 会自动删掉语气词，交付不了 |
| 歌曲转歌词 | 有音乐时识别准确率明显下降，而且涉及歌词版权 |
| 焦点小组、需要区分说话人的场景 | 没有说话人区分功能 |
| Voicemail 转文字 | 这类搜索主要是在找运营商的语音信箱功能，意图对不上 |
| 微信语音转文字 | 微信导出的语音是 SILK / AMR，浏览器解码不了 |
| AMR / WMA / AIFF / CAF 格式页 | 主流浏览器无法稳定解码 |
| `/mp3-to-srt`、学生 / 记者等人群页 | 和现有的 `/audio-to-srt`、`/lecture-transcription`、`/interview-transcription` 重复，内容并进这些现有页面 |
| speech to text / voice to text 泛词 | 搜这些词的人多半想要实时听写，而且和首页意图重叠 |
| 波斯语等 AdSense 不支持的语言 | 这些页面挂广告就违规 |
